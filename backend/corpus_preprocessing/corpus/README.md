# Препроцессинг корпуса

Девять PDF с аналитикой Альфа-Банка — сканы без текстового слоя. `pdffonts`
не находит ни одного встроенного шрифта, `pdftotext` возвращает ноль слов.
Наивный парсер построит пустой индекс. Этот скрипт распознаёт страницы один
раз, кладёт результат в репозиторий и больше к моделям не обращается.

```
pdf/*.pdf  →  corpus/<doc_id>/page_NN.md  →  corpus/chunks.jsonl
```

## Запуск

```bash
apt-get install -y poppler-utils tesseract-ocr tesseract-ocr-rus

# основной путь
python3 build_corpus.py --pdf-dir pdf --out corpus --backend tesseract

# страницы с графиками и таблицами — через мультимодальную модель
export LLM_BASE_URL=... LLM_API_KEY=... LLM_VISION_MODEL=Qwen3-VL-30B-A3B-Instruct
python3 build_corpus.py --pdf-dir pdf --out corpus --backend vlm --max-cost-rub 60

# проверить конвейер, ничего не распознавая
python3 build_corpus.py --pdf-dir pdf --out corpus --backend mock
```

Повторный запуск **ничего не тратит**: уже распознанные страницы берутся из
готовых `.md`. Перераспознать принудительно — `--force`. При лимите в 500 ₽
это главное свойство скрипта.

## Что на выходе

`corpus/<doc_id>/page_NN.md` — страница с YAML-заголовком: `doc_id`, `title`,
`publisher`, `as_of_date`, `page`, `page_type`, `topics`, `stale`, `priority`,
`sha256`. Файлы коммитятся в репозиторий.

`corpus/chunks.jsonl` — готовый вход для векторной базы. Поля чанка те же
плюс `chunk_id`, `ref` вида `corpus://policy_rate#p1` и сам `text`. Именно
`ref` попадает в `evidence[].ref` инсайта, а `as_of_date` — в
`interpretation.bank_view.as_of_date`.

`corpus/manifest.json` — чем и когда собрано, сколько страниц распознано,
сколько взято из кэша, сколько отброшено, израсходованные токены и стоимость.
Плюс список документов, отсортированный по дате — он нужен для разрешения
темпоральных конфликтов.

## Что скрипт выбрасывает и почему

На прогоне из 64 страниц в индекс попадают 45.

**Девять дисклеймеров.** Почти идентичный юридический шаблон, набитый словами
«ценные бумаги», «риски», «валютный риск». Семантически они близки к любому
финансовому запросу и будут всплывать в выдаче, съедая топ-k. Отсев идёт по
реестру и дублируется регуляркой по тексту: если шаблон распознан, страница
не индексируется, что бы ни говорил реестр.

**Шесть титульных и разделительных слайдов.** Два-восемь слов, индексировать
нечего.

**Четыре страницы отчёта по стали.** Документ датирован апрелем 2021 года, в
список девяти материалов приложения 2 ТЗ не входит и содержит целевые цены
акций пятилетней давности. По умолчанию исключён целиком. Включается флагом
`--include-stale` — и это стоит сделать один раз на репетиции, чтобы показать
жюри, как темпоральный фильтр отбрасывает устаревший источник.

## Реестр

`corpus_registry.json` — метаданные девяти документов, проставленные вручную
после постраничного чтения. Дату публикации и издателя распознаванием надёжно
не достать, а без `as_of_date` корпус бесполезен: в нём лежат пять версий
прогноза ключевой ставки за полтора месяца, и семантический поиск без фильтра
по дате вернёт устаревшую цифру большинством голосов.

Реестр первичен при классификации страниц. Эвристика по числу слов работает
только там, где реестр молчит: страница с графиками и десятком подписей — это
содержание, а не титул, и выбрасывать её по счётчику слов нельзя.

Если в файле оказалось не столько страниц, сколько записано в реестре, скрипт
не падает, а печатает предупреждение: реестр устарел, нужна ручная сверка.

## Нарезка на чанки

Чанк — смысловой блок, а не окно фиксированной длины. Режется по заголовкам
Markdown и пустым строкам, короткие куски склеиваются до 220 символов,
длинные разбиваются по границам предложений до 1800. Таблицы не режутся
никогда: разорванная пополам таблица прогнозов хуже длинного чанка.

## Выбор бэкенда

| Бэкенд | Когда | Чего ждать |
| --- | --- | --- |
| `tesseract` | основной прогон | текст берёт хорошо, подписи к графикам — хуже |
| `vlm` | страницы с графиками и таблицами | берёт и то и другое; считает токены и останавливается по `--max-cost-rub` |
| `text` | если у PDF есть текстовый слой | мгновенно, бесплатно |
| `mock` | проверка конвейера | ничего не распознаёт |

Разумная стратегия на неделю: весь корпус через `tesseract`, затем `--force`
точечно по страницам с таблицами прогнозов через `vlm`. Таких страниц пять:
`policy_rate` с. 2, `macro_7m26` с. 3, `macro_1h26` с. 4, `fi_strategy_3q26`
с. 24 и 26. Именно из них берутся числа, на которые ссылаются инсайты.

## Проверено

Конвейер прогнан целиком на всех девяти файлах с бэкендом `mock`:
60 страниц, 45 оставлено, 15 отброшено, 90 чанков, манифест собран.
Повторный запуск взял все 45 страниц из кэша и не потратил ничего.
Ошибки при отсутствующем языковом пакете и незаданных ключах модели
выводятся текстом, а не трассировкой.

Не проверено: качество самого распознавания — в среде сборки нет русского
языкового пакета `tesseract`. Это первое, что нужно прогнать у себя.
