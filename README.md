# ALFA BUSINESS × TWILIGHT
## Новостная аналитика для принятия бизнес-решений

Интеллектуальный сервис для руководителей крупного бизнеса, который превращает поток внешних новостей и аналитики Альфа-Банка в персонализированные бизнес-инсайты. Сервис определяет контекст компании, отбирает значимые события и объясняет их влияние с учетом внешних источников и экспертизы банка.

---

## 1. Аннотация и цель проекта

Крупные компании работают с большими объемами информации, и руководителю важно не просто узнать новость, а понять, как она повлияет на его бизнес. Наш сервис решает проблему «информационного шума»: мы не пересказываем новости, а даем персонализированную интерпретацию события, риски, возможности и рекомендации, опираясь на данные компании и аналитику Альфа-Банка.

Сервис реализует полный цикл обработки:
1. Получение события (в прототипе — через API).
2. Детерминированный скоринг (отсев нерелевантных новостей без затрат токенов LLM).
3. Поиск релевантной аналитики банка (RAG).
4. Генерация инсайта (что произошло, почему это важно, риски, возможности, рекомендации).
5. Отображение в интерфейсе, похожем на интернет-банк.

    ▼

    ▼

    │
    ▼
[Frontend (frontend/)] ──► UI с трассировкой, ролями и чатом
